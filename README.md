# Meltwater Opportunity Radar

Interactive hackathon prototype for an AI-powered opportunity intelligence layer within the Meltwater Suite.

## Overview

Opportunity Radar turns cross-channel intelligence into prioritized, actionable growth opportunities. The prototype combines signals from media, social, creator, competitive, and generative-AI intelligence to help users identify where a brand can act next.

## Prototype flows

- **Radar** — discover and filter prioritized opportunities
- **Opportunity Depth** — inspect evidence, reasoning, timing, fit, and opportunity score
- **Action Plan** — convert an opportunity into an execution plan
- **Activated Opportunities** — monitor activated opportunities and KPI movement
- **Engine Expansion** — show how GenAI and Competitive Intelligence strengthen the Opportunity Radar engine

## Interactive features

- Brand selector with multiple demo brands
- Opportunity-type filtering
- Live / Last 7 days / Last 30 days timeframe controls
- Human-in-the-loop flag feedback
- Action-plan creation and activation monitoring
- Collapsible Meltwater-style navigation
- Embedded brand assets for a portable single-file demo

## Run locally

Open `index.html` directly in a modern browser.
